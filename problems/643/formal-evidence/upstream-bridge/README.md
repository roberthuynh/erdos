# Bridge to the actual Formal Conjectures definitions

`ActualImportBridge.lean` imports `FormalConjecturesForMathlib.Combinatorics.Hypergraph.Finite` and the local `Openmath.Erdos643R3.FCBridge`. It proves that the upstream `Finset.HasRepeatedDisjointUnion` is the local forbidden configuration, that upstream 3-uniformity is the local uniformity predicate, and that the already proved 24/23 upper bound applies to upstream `Hypergraph.extremalNumber` and its `+1` forcing expression. It does not prove asymptotic equality with coefficient one.

The three files under `vendor/` are byte-for-byte copies of the corresponding source files at `google-deepmind/formal-conjectures` commit `95b199bfbc08f7b1183196bab59ed3b08f27c2c9`. Their original copyright and Apache 2.0 notices are retained; [LICENSE.upstream](LICENSE.upstream) is the upstream license. `source-manifest.json` gives all SHA-256 values. This is a narrow source snapshot, not a claim that the older locally pinned Formal Conjectures package already contains these definitions. That older package lacks the `Finite` and `Basic` modules.

The upstream commit pins Lean `v4.33.1` and Mathlib tag `v4.33.1`, matching this package's Lean toolchain and Mathlib commit `0df444a360eaa60ab8c11dca51a86af692955474`. An isolated direct Lean build of the three exact upstream source files and `ActualImportBridge.lean` passed; the four bridge declarations used only `propext`, `Classical.choice`, and `Quot.sound`, and `leanchecker` replay passed for all four modules. The [check receipt](receipts/actual-bridge-check.log) records the exact source hashes and outcomes. A separate [isolated Lake build](receipts/lake-actual-bridge.log) also passed for the exported subproject using the separately verified pinned package cache. It did not redownload dependencies from a clean checkout.

To rebuild from a clean checkout with Lean 4.33.1, Git, Python 3, and GNU `timeout` installed (available through coreutils' `gnubin` directory on macOS), run `./prefetch.sh`, `lake exe cache get`, then `lake build ActualImportBridge` in this directory. These commands fetch the pinned Mathlib dependency; no private project paths are required.
